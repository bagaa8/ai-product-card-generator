# Генератор карточек товаров по фото

Учебный проект, который анализирует изображение товара и помогает создать описание для интернет-магазина.

## Как работает проект

- Принимает фотографию товара — её можно загрузить или указать ссылку.
- BLIP анализирует изображение и создаёт описание на английском языке.
- RAG с FAISS ищет подходящие SEO-ключи в базе знаний.
- Gemini объединяет результаты и генерирует продающую карточку товара на русском языке в формате Markdown.
- Gradio предоставляет интерфейс, который можно запустить в Google Colab.

## Используемые технологии

- **BLIP** — анализ изображений и генерация описаний.
- **FAISS** — поиск похожих записей в базе знаний.
- **Sentence Transformers** — создание векторных представлений текста.
- **Google GenAI SDK** — работа с Gemini.
- **Gradio** — пользовательский интерфейс.
